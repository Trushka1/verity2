# Проверка и поиск СНИЛС

Лабораторная работа № 2 «Регулярные выражения. Unit-тестирование».
Вариант 10.

Программа проверяет формат СНИЛС, введённого с клавиатуры,
и ищет записи в текстовом файле UTF-8.

## Запуск

```text
python main.py
```

Выбери `1` для проверки строки или `2` для поиска в файле.
Пример файла — `example.txt`.

## Тесты

```text
python -m unittest discover -s tests -v 
```
